# GRAB A CUP 企業採購專區

## 功能
- 全站產品價格標示由「測試價」改為「售價」
- 新增 `enterprise.html`
- 企業代號登入後才會由後端回傳企業價格
- 企業價 = 一般售價 × 80%，四捨五入至整數元
- 企業價格不與一般零售滿件／滿額折扣疊加
- 企業採購結帳金額由後端重新計算，前端無法自行竄改企業價
- 登入 Token 12 小時失效，儲存在瀏覽器 sessionStorage

## 正式上線前
在伺服器環境變數設定：

```env
ENTERPRISE_CODES=COMPANY-A,COMPANY-B
ENTERPRISE_SECRET=請換成長且隨機的安全字串
```

Stage / 開發環境若沒有設定 `ENTERPRISE_CODES`，預設可使用 `GRAB2026` 測試。
正式環境不會自動提供預設企業代號。

> 重要：企業代號不能只寫在 HTML 或 JavaScript，否則任何人都能查看原始碼取得。此版本已將驗證放在 Node.js 後端。
